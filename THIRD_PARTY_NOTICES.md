## License Text Locations

The local build downloads upstream packages into ignored directories. Their
license files can be found after running `scripts/prepare_packages.py`, for
example:

- `packages/winui/*/license.txt`
- `packages/winui/*/LICENSE*`
- `packages/winui/*/NOTICE.txt`
- `packages/downloads/SourceHanSansSC/LICENSE.txt`
- `packages/downloads/SourceHanSansTC/LICENSE.txt`
- `schemas/wanxiang/current/LICENSE`

Release installers include this notice as `THIRD_PARTY_NOTICES.txt`, the
project license as `LICENSE.txt`, and redistributed upstream license texts in
the `THIRD_PARTY_LICENSES` directory. That directory also includes
`THIRD_PARTY_SOURCE_OFFER.txt` with corresponding source URLs for bundled
third-party binaries, including GPL-licensed components.
